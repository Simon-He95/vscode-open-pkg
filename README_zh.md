快速打开某一个第三方库的主页：选中包名 + `command+r` 打开外部浏览器，或者将光标放在 *import* / *require* / `import()` 的行上（或放在带引号的包名内）按下 `command+r`，会自动解析包名并打开外部浏览器；支持 `react-dom/client` 这类子路径导入（会打开 `react-dom`）。若未找到 homepage，则会回退到 repository，再回退到 npm 包页面。
